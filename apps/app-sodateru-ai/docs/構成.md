# 構成メモ（開発者向け）

- **正本**: GitHub `Masahieo-A/Aomatsu_web` の `apps/app-sodateru-ai`（2026-09-26 に単独リポジトリ `Masahieo-A/sodateru-ai` から移転）
- **本番**: Cloudflare Workers `sodateru-ai` — https://sodateru-ai.aomatsu-apps.workers.dev/
- **Web**: Next.js 16 / React 19 / TypeScript / Tailwind CSS 4
- **Cloudflare互換層**: vinext（`vite.config.ts`、ビルド成果物は `dist/`）
- **DB**: Cloudflare D1（`sodateru-ai`）。スキーマは `migrations/`、実行時バインディング名は `DB`
- **認証**: Google OpenID Connect。`hd` と検証済みメールの両方で `tomidah.com` に限定
- **教員権限**: `TEACHER_ALLOWLIST` またはD1 `teacher_allowlist` の明示登録
- **AI**: Gemini API。入力サイズ制限、参加者所有権確認、再送用の冪等化をAPI側で実施
- **教材**: JSON Schema、実行時バリデータ、サンプルを `curriculum/` と `lib/curriculum/` に配置
- **UI**: English Hub 共通ヘッダーと配色トークン（monorepo `docs/design-system.md` 準拠）を `app/layout.tsx`・`app/globals.css` に設置

## 設定値

Cloudflareに設定する値は `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`AUTH_SECRET`、`GEMINI_API_KEY`、`TEACHER_ALLOWLIST`（シークレット）と `APP_URL`（`wrangler.jsonc` の `vars`）です。秘密値はリポジトリへコミットしません。ローカルでは `.dev.vars` に置きます。

## デプロイ

このフォルダで `npm run build:vinext` → `npm run deploy:vinext`（wrangler のログインが必要）。D1 のスキーマ変更時は先に `npx wrangler d1 migrations apply DB --remote --config wrangler.jsonc`。
